# Branch management

All branch should originate from main, there is no dev or develop branch on this repository

## Branch naming convention

Any branch should use the following prefixes and should be structured as:

```
<type>/<description>
```


Purpose Prefixes — describe the intent of the work:

    feat/   : For new features (e.g., feat/add-login-page)
    fix/    : For bug fixes (e.g., fix/header-bug)
    hotfix/ : For urgent fixes (e.g., hotfix/security-patch)
    release/: For branches preparing a release (e.g., release/v1.2.0)
    chore/  : For non-code tasks like dependency, docs updates (e.g., chore/update-dependencies)
